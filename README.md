# 1v1 Tetris Mobile (Rounded Board)

🎮 **1v1 테트리스 게임 – 모바일 전용**  
HTML5 Canvas 기반 브라우저용 테트리스 게임입니다.  
두 플레이어가 동시에 플레이 가능하며, 각자의 보드가 **둥근 테두리**로 표시됩니다.

---

## 🎯 특징
- 2인용 테트리스 대전
- 각 플레이어의 점수와 최고점 표시
- 블록 하드드랍 위치를 **반투명 고스트 블록**으로 미리 보여줌
- 점수를 올리면 블록이 잠깐 흔들리는 **Shake Effect**
- 게임 오버 시 승리자 표시 및 재시작 가능
- **모바일 터치 버튼 지원**
- 화면 크기에 맞춘 **자동 스케일링**

---

## 🤏 모바일 컨트롤
- 화면 하단의 터치 버튼으로 이동, 회전, 소프트/하드 드랍 가능
- 각 플레이어 별 버튼 배치:
  - ◀ : 왼쪽 이동
  - ▶ : 오른쪽 이동
  - ⟳ : 회전
  - ▼ : 소프트 드랍
  - ⬇ : 하드 드랍
- 게임 오버 후 **재시작 버튼**으로 다시 플레이 가능
